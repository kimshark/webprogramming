# 🌌 Cosmic UI - React Web Application

최신 트렌드를 반영한 다크 테마(Dark Theme)와 글래스모피즘(Glassmorphism) 기반의 모던 React 웹사이트입니다.

## 🔗 Live Demo (배포 링크)
- **URL:** https://webprogramming-liard.vercel.app/

## 🛠 Features (주요 기능)
- **Navbar:** 블러 처리된 상단 네비게이션 바
- **Hero:** 시선을 사로잡는 타이틀 영역
- **Cards:** 마우스를 올릴 때 부드러운 효과를 내는 소개 카드 (`Props`를 활용해 동적 랜더링)
- **Contact:** 텍스트와 이메일 입력을 받는 문의 폼
- **Footer:** 프로젝트 하단 정보
