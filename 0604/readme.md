1. fork()와 pid 변수의 비밀 (세포 분열)개념: 실행 중인 프로세스를 똑같이 복제하여 새로운 자식 프로세스를 만드는 시스템 호출입니다.리턴값 규칙 (가장 중요!): pid = fork();가 실행되면 프로세스가 2개로 쪼개지며, pid 변수에는 각자 다른 값이 들어갑니다.👨 부모 프로세스: 진짜 자기 PID는 유지하면서, 변수 pid에는 방금 태어난 자식의 진짜 PID 값을 받습니다. (자식 번호 안내장)👶 자식 프로세스: 진짜 자기 PID는 따로 발급받지만, 변수 pid에는 내가 자식이라는 신호인 0을 받습니다.getpid()의 필요성: getpid()를 쓰지 않고 pid 변수만 출력하면 부모는 자식 PID를, 자식은 0만 출력합니다. 진짜 내 주민등록번호를 알려면 반드시 OS에게 getpid()로 직접 물어봐야 합니다.2. 연속 fork()의 마법 (트리 구조)fork()를 연속으로 쓸 때마다 프로세스는 $2^n$개로 기하급수적으로 늘어납니다.fork() 2번: 총 4개 프로세스 생성 (부모, 첫째 자식, 둘째 자식, 손자)fork() 3번: 총 8개 프로세스 생성규칙: 3번째 fork()를 실행했을 때, 마지막에 막 태어난 막내 세대(둘째 자식 계열, 손자 계열 등) 정확히 4개의 프로세스가 pid 변수 값으로 0을 리턴받습니다. (전체 개수의 딱 절반)3. 실행 순서와 PID의 특징 (OS의 독점 권한)실행 순서: fork()로 여러 프로세스가 생겼을 때, 누가 먼저 실행될지는 OS 스케줄러 마음(랜덤)입니다. 예측이 불가능하므로 순서를 맞추려면 wait() 함수를 써야 합니다.PID 값 예측/지정: 프로그래머가 원하는 숫자로 PID를 직접 지정하거나, 발급 규칙을 정할 수 없습니다. 보안(PID 예측 공격 방지)과 시스템 안정성을 위해 OS가 철저하게 무작위(Random) 등으로 독점 관리합니다.4. exec() 시스템 호출 (영혼 갈아끼우기)개념: 현재 프로세스의 메모리 공간에 하드디스크에 저장된 다른 '실행 파일'(예: /bin/ls나 내가 만든 다른 프로그램)을 가져와 덮어씌우는 것입니다.특징: * 옷과 영혼(코드)은 완전히 새 파일로 바뀌지만, OS가 준 진짜 PID(주민등록번호)는 그대로 유지됩니다.exec()가 성공하면 그 뒤에 있던 기존 코드는 완전히 증발해서 실행되지 않습니다.그래서 보통 fork()로 분신(자식)을 먼저 만들고, 그 자식에게 exec()를 시켜서 다른 파일을 실행하게 만듭니다.
